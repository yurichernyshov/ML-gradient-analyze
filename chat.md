# История взаимодействия

## Цель работы
Разработка пайплайна бинарной классификации с анализом градиентов, обнаружением атак и визуализацией результатов.

## Шаг 1: Генератор данных
**Дата:** 08.10.2026
Создан `data_generator.py` — генерация датасета через sklearn `make_classification`. 1000 образцов, 10 признаков, 800/200 train/test. Настроено виртуальное окружение через `uv`, установлены зависимости.

## Шаг 2: Нейронная сеть на PyTorch
Установлен PyTorch (CPU версия). Создан `neural_network.py`:
- `BinaryClassifier` — MLP (10→64→32→1) с BatchNorm, Dropout
- `GradientAnalyzer` — извлечение градиентов, L2-норма, статистика
- `train_model` — функция обучения с историей

## Шаг 3: Атаки на модель
Создан `attacks.py`:
- `label_flipping` — инверсия случайных меток
- `targeted_poisoning` — добавление зашумлённых образцов целевого класса

## Шаг 4: Обнаружение аномалий
Создан `anomaly_detection.py`:
- `IQRDetector` — межквартильный размах
- `ZScoreDetector` — Z-оценка
Тестирование на градиентах clean vs poisoned моделей.

## Шаг 5: Обучение с контролем градиентов
Создан `gradient_control.py`:
- `GradientController` — clipping, vanishing detection, anomaly monitoring
- `TrainedWithGradientControl` — полный цикл обучения
Результат: 113 клиппингов, 42 аномалии обнаружено, accuracy 0.920 (vs baseline 0.905).

## Шаг 6: Визуализация
Создан `visualization.py`:
- 6-панельный дашборд (loss, accuracy, gradient L2, distribution, anomaly timeline, comparison)
- Сгенерированы `results_dashboard.png` и `comparison.png`
